# 自動改ページ

見えているタブごとに、次ページまたは指定ページのアクションでページを送ります。

| 項目 | 値 |
| --- | --- |
| ID | `com.ezco.auto_page` |
| バージョン | `1.0.0` |
| 種別 | サイドバー |
| 入口 | `plugin:AutoPagePlugin` |
| LICENSE | ルートの `LICENSE.md` |

## 使い方

1. このフォルダをデータフォルダの `plugins/` 直下に置く
2. EzCo を起動（追加したあとは再起動）
3. プラグイン設定で有効にする
4. サイドバーの「自動改ページ」を開く

開始ページ、終了ページ、間隔（秒）、現在のページから、現在のページまで、開始、ループがあります。ループの初期はオンです。開始中は開始が停止になります。間隔の初期値はプラグイン設定で、既定は 1 秒、1 秒から 86400 秒です。欄をまだ変えていないタブはこの値を使い、設定を変えると次の間隔から反映されます。サイドバーで秒数を変えたタブは、その値のままです。

タブごとに開始できます。欄はショートカットが効くタブの値です。見えているタブだけ送ります。隠れていた時間はまとめず、再び見えたあとは間隔が過ぎてから再開します。分割で見えていれば送ります。ページスライダーを閉じていても送ります。

範囲の中はそのページから次へ送ります。範囲の外で開始すると、待たずに開始ページへ移ります。終了ページの次は、ループがオンなら開始ページへ戻り、オフなら止まります。手動でページが変わったタブは止まります。ファイルが変わったタブは、開始を 1、終了を新しいページ数に戻して止まります。
