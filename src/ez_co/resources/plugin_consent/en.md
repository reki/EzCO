# Load plugins

EzCo does **not inspect** plugin code. Code in a ZIP or folder runs with the same privileges as the app once you place it.

- The EzCo developers are not responsible for damage from malicious or defective plugins
- Trust the publisher, and read the source if needed
- Responsibility lies with the plugin publisher and the person who installs it

See `plugins/README.md` in the app for the full notice.
