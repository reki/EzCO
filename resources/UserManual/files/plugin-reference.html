🔌 プラグインリファレンス

本体がプラグインに渡す契約です。JavaDoc のように型と引数を並べています。ユーザー向けの配置手順は プラグイン設定 を、開発者向けの長文はリポジトリの docs/plugins.md を見てください。

API バージョン: 1　／　配置: 実行ファイル旁 plugins/ の ZIP のみ

概要

プラグインはホストから生成され、コールバックされるだけです。コンストラクタは常に Class(root, get_text, host) です。import ez_co はできません。PySide6 と本体が入れているサードパーティは import できます。

画像／アーカイブの読み込み契約
host
登録・設定・ダイアログ・アクション
get_text
多言語文言
root
ZIP 内リソース

パッケージ構造

my_plugin.zip
├── manifest.json
├── src/                 # import ルート
│   └── loader.py
├── langs/               # 任意 ja.json / en.json
└── resources/           # 任意。root.read_bytes

余分な親フォルダを挟まないでください。開発フォルダを置いても、ホストが読むのは同名の ZIP です。

manifest.json

ZIP の直下に置きます。ホストはこのファイルだけを見てプラグインを識別します。

id string 必須

プラグイン ID。設定の保存キーは id(ver:version) です。プラグイン設定の ID 列にはバージョンを付けません。

name string 必須

一覧に出す表示名です。

version string 必須

パッケージ版です。上げると設定キーが変わり、以前の保存値は引き継ぎません。

api_version int 必須

ホスト契約の版です。現在は 1 だけが有効です。

entry string 必須

モジュール:クラス です。src/ を import ルートとして読みます。例: loader:FileLoader は src/loader.py の FileLoader。

description string 任意

プラグイン設定に出す短い説明です。

author string 任意

作者名です。

サンプル（画像ローダー）

{
  "id": "com.example.png_loader",
  "name": "Example PNG Loader",
  "version": "1.0.0",
  "api_version": 1,
  "entry": "loader:FileLoader",
  "description": "Sample .png loader.",
  "author": "Example"
}

サンプル（サイドバー）

{
  "id": "com.example.sidebar",
  "name": "My Sidebar",
  "version": "1.0.0",
  "api_version": 1,
  "entry": "plugin:MyPlugin",
  "description": "Shows info for the current folder.",
  "author": "Example"
}

FileLoader

ホストが manifest.entry のクラスを生成し、決まった名前のメソッドを呼びます。ez_co.plugins.api は import しません。サイドバーだけのプラグインでも同じコンストラクタです。

画像ローダーの最小例（src/loader.py）

class FileLoader:
    def __init__(self, root, get_text, host):
        self.root = root
        self.get_text = get_text
        self.host = host
        host.register_format(".png", "image")

    def get_file_count(self, file_path):
        return 1

    def list_entries(self, file_path):
        return [file_path.replace("\\", "/").split("/")[-1]]

    def read_entry(self, file_path, index):
        with open(file_path, "rb") as handle:
            data = handle.read()
        return _Entry(self.list_entries(file_path)[index], data)


class _Entry:
    def __init__(self, name, data):
        self.name = name
        self.data = data
ctorClass(root, get_text, host)

唯一の生成経路です。使わない引数も受け取って保持します。

引数説明
rootZIP 内ファイル。read_bytes / exists

methodsupported_formats() -> sequence

互換用。新規は host.register_format を使います。ホストは掃引直後に登録結果を集め、無ければこのメソッドを呼びます。

image は1枚、archive は中身をページにします。

def supported_formats(self):
    return [(".png", "image")]
    # または [{"extension": ".zip", "kind": "archive"}]
methodget_file_count(file_path: str) -> int

画像エントリ数。アーカイブなら len(list_entries(...))、画像なら通常 1。

def get_file_count(self, file_path):
    return len(self.list_entries(file_path))
methodlist_entries(file_path: str) -> sequence[str]

エントリ名の列。ディレクトリは返さない。返した順がページ順です。暗号化アーカイブはここでパスワードを取らないと件数 0 になります。

def list_entries(self, file_path):
    names = []
    with ZipFile(file_path) as archive:
        for name in archive.namelist():
            if name.endswith("/"):
                continue
            if name.lower().endswith((".png", ".jpg", ".webp")):
                names.append(name)
    return names
methodread_entry(file_path: str, index: int) -> object

name（str）と data（bytes、PIL が開ける画像）を持つオブジェクトを返します。ワーカーから呼ばれることがあります。UI はホスト API 経由。

def read_entry(self, file_path, index):
    name = self.list_entries(file_path)[index]
    with ZipFile(file_path) as archive:
        data = archive.read(name)
    return _Entry(name, data)
methodsetup() / teardown()

任意。有効化で setup、無効化で teardown のあとホストがサイドバーとアクションを外します。設定スキーマは残ります。

def setup(self):
    widget = self.host.load_ui(self.root.read_bytes("resources/sidebar.ui"))
    self.host.register_sidebar("info", self.get_text("title"), widget)
    self.host.on("current_changed", self._on_current)

def teardown(self):
    self.host.off("current_changed")

host

コンストラクタ第 3 引数。同じ名前はモジュール組み込みにも渡ります。プラグインから bind は呼びません。

methodhost.register_format(extension, kind) -> None

kind は "image" / "archive"。__init__ で登録してよい。

host.register_format(".png", "image")
host.register_format(".xyz", "archive")
methodhost.register_sidebar(sidebar_id, title, widget_or_layout, aliases=None) -> None

QWidget または QLayout。ドック化は本体。開閉アクション plugin:{plugin_id}:sidebar:{sidebar_id} を自動登録します。ドックの題名は title のまま、ショートカット／ジェスチャーの表示は本体が {title}サイドバー表示/非表示 にします。aliases は旧ショートカット ID など。本体は特定プラグインの ID を知りません。

widget = QWidget()
host.register_sidebar("info", get_text("title"), widget)
# 公開 ID: plugin:com.example.sidebar:sidebar:info

host.register_sidebar(
    "info",
    get_text("title"),
    widget,
    aliases=("toggle_my_dock",),
)
methodhost.unregister_sidebar(sidebar_id) -> None

サイドバーと自動登録した開閉アクションを外します。

host.unregister_sidebar("info")
methodhost.register_action(action_id, label, callback, aliases=None) -> None

独自アクション。公開 ID は plugin:{plugin_id}:{action_id}。action_id に sidebar と : は使えません。ショートカット／ジェスチャーの候補に出ます。既定キーは付きません。

def _reload():
    self._refresh(host.get_current("folder"))

host.register_action("reload", get_text("reload"), _reload)
# 公開 ID: plugin:com.example.sidebar:reload
methodhost.unregister_action(action_id) -> None

独自アクションを外します。ユーザーの割り当ては設定に残ります。

host.unregister_action("reload")
methodhost.register_config(key, value_type, default=None, label=None, description=None) -> None

value_type は "bool" / "string" / "int"。無効化してもスキーマは残るので __init__ で登録してよい。一覧に「設定」ボタンが出ます。

host.register_config(
    "fetch_web",
    "bool",
    default=True,
    label=get_text("config.fetch_web"),
    description=get_text("config.fetch_web.desc"),
)
methodhost.get_config(key, default=None) -> Any

自プラグインの保存値。未保存ならスキーマの default。他プラグインの行は読めません。

if host.get_config("fetch_web", True):
    self._fetch(folder)
methodhost.set_config(key, value) -> bool

型を正規化して保存し、そのプラグインへ config_changed（{key, value}）を送ります。

host.set_config("fetch_web", False)
methodhost.delete_config(key) -> bool

保存値を消します。スキーマは残ります。

host.delete_config("fetch_web")
methodhost.load_ui(bytes_or_path) -> QWidget

Designer の .ui を QUiLoader で読みます。

widget = host.load_ui(self.root.read_bytes("resources/sidebar.ui"))
title = widget.findChild(QLabel, "titleLabel")

folder = host.get_current("folder")

methodhost.on(event, callback) / host.off(event, callback=None)

current_changed と config_changed。off で callback を省略するとそのイベントの自プラグイン分を全部外します。

def _on_current(payload):
    self._refresh(payload.get("folder"))

def _on_config(payload):
    if payload.get("key") == "fetch_web":
        self._refresh(host.get_current("folder"))

host.on("current_changed", _on_current)
host.on("config_changed", _on_config)
host.off("current_changed")
methodhost.get_app_config() -> Mapping

読み取り専用。language / viewer / cache / ui_font だけです。

lang = host.get_app_config().get("language")
methodhost.ask_password(file_path, mismatch=False, verify=None) -> str | None

本体のパスワードダイアログ。セッションと履歴も見ます。ワーカーから呼んでも UI スレッドで動きます。None はキャンセルまたはアプリ終了です。

password = host.ask_password(
    file_path,
    verify=lambda pwd: self._can_open(file_path, pwd),
)
if password is None:
    raise RuntimeError("password cancelled")
methodhost.show_dialog(name, **kwargs) -> Any

password / archive_password / ask_password は ask_password と同じ。それ以外は警告して None。

password = host.show_dialog("ask_password", file_path=file_path)
methodhost.run_action(action_id, **kwargs) -> bool

本体アクション（例 new_tab）または登録済みプラグインアクションを呼びます。未対応なら False。

host.run_action("new_tab")

get_text

funcget_text(key: str, **kwargs) -> str

探索順: プラグイン langs/{言語}.json → プラグイン ja/en → 本体。同じキーはプラグインが勝ちます。str.format(**kwargs) を使えます。

langs/ja.json

{
  "title": "商品情報",
  "reload": "再読み込み",
  "status": "{count} 件"
}
title = get_text("title")
status = get_text("status", count=3)

root

methodroot.read_bytes(relative_path: str) -> bytes

ZIP 内の相対パス。無ければ KeyError。

ui = root.read_bytes("resources/sidebar.ui")
icon = root.read_bytes("resources/icon.png")
methodroot.exists(relative_path: str) -> bool

ZIP 内にあるか。

if root.exists("resources/sidebar.ui"):
    widget = host.load_ui(root.read_bytes("resources/sidebar.ui"))

イベント

current_changed

表示中のファイルが変わったとき。payload は {path, folder, page} です。

config_changed

自プラグインの set_config のあと。payload は {key, value} です。他プラグインの変更は来ません。

def _on_current(payload):
    print(payload["folder"], payload["page"])

def _on_config(payload):
    print(payload["key"], payload["value"])

host.on("current_changed", _on_current)
host.on("config_changed", _on_config)

制約

  • import ez_co / 他プラグインの import は不可
  • ドックの貼り付け／フローティングは本体
  • 他プラグインの設定は読めない（plugin_id はハッシュ化）
  • DLL プラグインは未対応
  • ZIP を足したら再起動が必要
