🚀 高度な機能

📦 アーカイブファイル

EzCoは様々なアーカイブ形式に対応しており、圧縮ファイルを展開せずに直接中身の画像を表示できます。

対応アーカイブ形式

📁

標準アーカイブ

ZIP, 7Z, RAR, TAR
一般的なアーカイブ形式に対応

📚

コミック形式

CBZ, CBR, PDF
コミック専用のアーカイブ形式とPDF

日本語ファイル名対応

EzCoは日本語を含むファイル名の自動エンコーディング判定に対応しています。

👆 マウスジェスチャー

右クリックを押しながらマウスをドラッグすることで、様々な操作を素早く実行できます。下表は、プロファイルが無い初回起動（または新規プロファイル作成）のときだけ入るデフォルトです。消した割り当ては再起動しても戻りません。

ジェスチャー アクション 説明
← 前のコミック 前のファイルに移動
→ 次のコミック 次のファイルに移動
↓ アプリケーション終了 EzCoを終了
↓→ フルスクリーン切り替え 全画面モードのON/OFF
↑↓ 最後に開いたファイル 履歴の最後の1件を開く
→← / ←→ 最初／最後のページ 先頭または末尾の画像へ移動

📑 ブックマーク機能

お気に入りのページをブックマークして、フォルダで整理して管理できます。

📌 ブックマーク追加

Ctrl + Shift + B
または機能／拡張 → ブックマーク追加/削除

📂 サイドバー表示

Ctrl + B
または機能／拡張 → ブックマーク

サイドバーの項目は、クリックで今のタブ、Ctrl+クリックまたは中央クリックで新しいタブ、右クリックでどちらにするか選べます。

📚 履歴機能

最近開いたファイルとその最後に見たページを自動的に記録し、簡単にアクセスできます。

💡 履歴機能

  • ファイルごとに最後に見たページを自動保存
  • 設定可能な履歴上限（1-99件）
  • 履歴サイドバーから素早くアクセス（クリックは今のタブ、Ctrl+クリックまたは中央クリックは新しいタブ）
  • 削除されたファイルの自動クリーンアップ

🔗 仮想パス機能

アーカイブファイル内の特定の画像ファイルを直接指定するためのパス形式です。

📋 基本構文

archive://アーカイブファイルのパス|アーカイブ内のファイル名

🖱️ コマンドライン起動

EzCo.exe "archive://path|file"

📝 ショートカット作成

デスクトップショートカットの引数に指定

🎨 カスタマイズ機能

EzCoは外部ファイルによる高度なカスタマイズに対応しています。

📝 カスタムフォント (font/ フォルダ)

💡 フォントのカスタマイズ

EzCoの実行ファイルと同じディレクトリにfont/フォルダを作成し、TTFファイルを配置することで、独自のフォントを使用できます。

1

フォルダの作成

EzCo.exeと同じディレクトリにfontフォルダを作成します。

EzCo.exe font/ ├── MyFont.ttf ├── CustomUI.ttf └── JapaneseFont.ttf
2

フォントファイルの配置

TTF形式のフォントファイルをfont/フォルダにコピーします。

3

設定での指定

設定ダイアログのフォント設定、またはエクスポートYAMLのui_font.font_familyで配置したフォント名を指定します。

ui_font: font_family: "MyFont"

⚠️ フォントに関する注意

  • 対応形式：TTF（TrueType Font）のみ
  • フォント名は拡張子を除いたファイル名で指定
  • 日本語フォントを使用する場合は、日本語文字に対応したフォントを選択
  • フォント変更は再起動後に反映されます

🌐 カスタム言語 (langs/ フォルダ)

💡 多言語サポート

EzCoは内蔵の日本語・英語に加えて、langs/フォルダにJSONファイルを配置することで、独自の言語や表記をカスタマイズできます。

デフォルト動作: 外部言語ファイルが存在しない場合、または無効な言語コードが指定された場合は、内蔵の日本語表示がデフォルトとして使用されます。

1

フォルダの作成

EzCo.exeと同じディレクトリにlangsフォルダを作成します。

EzCo.exe langs/ ├── ja.json # 日本語カスタマイズ ├── en.json # 英語カスタマイズ ├── zh.json # 中国語（新規言語） └── kr.json # 韓国語（新規言語）
2

言語ファイルの作成

JSON形式で言語データを定義します。内蔵言語ファイルと同じ構造を使用してください。

{ "app_name": "EzCo", "language": "中文", "language_code": "zh", "ui": { "file": "文件", "edit": "编辑", "view": "查看", ... } }
3

言語の選択

設定ダイアログの言語設定、またはエクスポートYAMLのlanguage.codeで言語ファイル名（拡張子なし）を指定します。

language: code: "zh" # langs/zh.json を使用

フォールバック動作: 指定した言語ファイルが存在しない場合、内蔵の日本語が自動的に使用されます。

💡 言語カスタマイズのヒント

  • 部分カスタマイズ: 一部の表記のみを変更したい場合は、該当項目のみを定義
  • 優先順位:
    1. 外部言語ファイル（langs/フォルダ）
    2. 内蔵言語ファイル（en.json、ja.json）
    3. デフォルト（内蔵日本語）※ファイルが存在しない場合
  • systemモード: language.code: "system"の場合、OSの言語設定に基づいて内蔵言語（日本語/英語）を自動選択
  • 文字エンコーディング: UTF-8で保存してください
  • 構造の確認: 内蔵のsrc/ez_co/resources/langs/を参考に

🔧 既存言語のカスタマイズ

日本語や英語の一部表記を変更したい場合

// langs/ja.json（部分カスタマイズ例） { "ui": { "next_page": "➡️ 次へ", "prev_page": "⬅️ 前へ" } }

🌍 新規言語の追加

完全に新しい言語を追加する場合

// langs/fr.json（フランス語例） { "app_name": "EzCo", "language": "Français", "language_code": "fr", "ui": { "file": "Fichier", "edit": "Édition", ... } }

⚠️ 言語ファイルに関する注意

  • JSON構文エラーがあると読み込みに失敗します
  • 不正な言語コードを指定すると、システムデフォルト言語にフォールバック
  • 言語変更は再起動後に反映されます
  • 必須項目（app_name、language_code等）は省略しないでください
