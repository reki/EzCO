Shortcut Settings

See the Action Reference for action names, IDs, behavior, and default assignments.

Change shortcuts

  1. Open Settings → Shortcut Settings.
  2. Choose Add, select an action, and press a keyboard or mouse input.
  3. To remove one, select its row and choose Delete.
  4. Choose OK. Changes update menus and controls immediately; no restart is needed.

Assignment rules

  • An action may have multiple assigned inputs.
  • The same input cannot be added to more than one action.
  • Defaults seed the first profile. A profile created from the menu copies the current settings and plugin-specific settings.
  • Normal restart does not restore deleted assignments. Importing a shortcut file does fill missing default actions.

Input names

Join modifiers with +, for example Ctrl+Shift+O.

TypeAvailable names
ModifiersCtrl, Alt, Shift, Meta
Navigation and special keysLeft, Right, Up, Down, Return, Escape, Space, Tab, Home, End, PageUp, PageDown
MouseMouseLeft, MouseRight, MouseMiddle, MouseWheelUp, MouseWheelDown, MouseX1, MouseX2

Change mouse gestures

  1. Open Settings → Gesture Settings.
  2. Choose Add and draw directions while holding the right mouse button.
  3. Select the action and confirm.

Directions use ← → ↑ ↓, and may be chained. Invert Mouse Lock requires both press and release, so it is not available for gestures.

The first profile includes gestures for previous/next comic, exit, fullscreen, reopen last file, first/last page, and page slider. See the Action Reference for details.

Import and export

Shortcut Settings exports only the shortcuts section as YAML.

shortcuts:
  next_page:
    - MouseLeft
    - Right
    - Space
  hold_mouse_lock:
    - Ctrl
    - MouseMiddle

Gesture Settings exports a JSON object from directions to action IDs.

{
  "←": "prev_comic",
  "→": "next_comic",
  "↓→": "fullscreen"
}

The general settings export is YAML and contains shortcuts and gesture_map together with the other settings.
