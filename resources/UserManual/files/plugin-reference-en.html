🔌 Plugin Reference

Contract the host gives to plugins, listed like Javadoc. For end-user install steps see Plugin Settings. Longer developer notes live in docs/plugins.md.

API version: 1　／　Location: a ZIP or a folder with manifest.json in the data folder plugins/ (Settings → Data location)

Overview

The host constructs the plugin and calls it. The constructor is always Class(root, get_text, host). import ez_co is not allowed. PySide6 and host third-party packages are allowed.

FileLoader
Image / archive loader contract
host
Register, config, dialogs, actions
get_text
Localized strings
root
Files inside the plugin

Package layout

my_plugin.zip
├── manifest.json
├── src/                 # import root
│   └── loader.py
├── langs/               # optional ja.json / en.json
└── resources/           # optional; root.read_bytes

Do not wrap the package in an extra parent folder. The same layout as a folder under plugins/ loads without zipping. If more than one plugin has the same id, choose one at startup. The choice is saved and is not asked again unless a new unresolved duplicate id appears. Change it later in Plugin Settings.

manifest.json

Place this at the ZIP or folder root. The host identifies the plugin from this file only.

id string required

Plugin id. Only one plugin with the same id is loaded at a time. Stored settings use the key id(ver:version). The ID column in Plugin Settings omits the version.

name string required

Display name shown in the plugin list.

version string required

Package version. Newer versions appear first in the duplicate-id dialog. Bumping it changes the settings key; previous values are not carried over.

api_version int required

Host contract version. Only 1 is valid today.

entry string required

module:Class. src/ is the import root. Example: loader:FileLoader loads FileLoader from src/loader.py.

description string optional

Short text shown in Plugin Settings.

author string optional

Author name.

Sample (image loader)

{
  "id": "com.example.png_loader",
  "name": "Example PNG Loader",
  "version": "1.0.0",
  "api_version": 1,
  "entry": "loader:FileLoader",
  "description": "Sample .png loader.",
  "author": "Example"
}

Sample (sidebar)

{
  "id": "com.example.sidebar",
  "name": "My Sidebar",
  "version": "1.0.0",
  "api_version": 1,
  "entry": "plugin:MyPlugin",
  "description": "Shows info for the current folder.",
  "author": "Example"
}

FileLoader

The host constructs the class from manifest.entry and calls fixed method names. Do not import ez_co.plugins.api. Sidebar-only plugins use the same constructor.

Minimal image loader (src/loader.py)

class FileLoader:
    def __init__(self, root, get_text, host):
        self.root = root
        self.get_text = get_text
        self.host = host
        host.register_format(".png", "image")

    def get_file_count(self, file_path):
        return 1

    def list_entries(self, file_path):
        return [file_path.replace("\\", "/").split("/")[-1]]

    def read_entry(self, file_path, index):
        with open(file_path, "rb") as handle:
            data = handle.read()
        return _Entry(self.list_entries(file_path)[index], data)


class _Entry:
    def __init__(self, name, data):
        self.name = name
        self.data = data

methodsupported_formats() -> sequence

Legacy. New plugins should call host.register_format. The host collects registrations first, then this method.

image is one page; archive lists inner images.

def supported_formats(self):
    return [(".png", "image")]
    # or [{"extension": ".zip", "kind": "archive"}]
methodget_file_count(file_path: str) -> int

Entry count. Archives: len(list_entries(...)). Images: usually 1.

def get_file_count(self, file_path):
    return len(self.list_entries(file_path))
methodlist_entries(file_path: str) -> sequence[str]

Entry names, not directories. Order is page order. Encrypted archives need a password here or the count is 0.

def list_entries(self, file_path):
    names = []
    with ZipFile(file_path) as archive:
        for name in archive.namelist():
            if name.endswith("/"):
                continue
            if name.lower().endswith((".png", ".jpg", ".webp")):
                names.append(name)
    return names
methodread_entry(file_path: str, index: int) -> object

Return an object with name (str) and data (bytes PIL can open). May run on a worker. Use host APIs for UI.

def read_entry(self, file_path, index):
    name = self.list_entries(file_path)[index]
    with ZipFile(file_path) as archive:
        data = archive.read(name)
    return _Entry(name, data)
methodsetup() / teardown()

Optional. Called on enable / disable. After teardown the host removes sidebars and actions. Config schemas stay.

def setup(self):
    widget = self.host.load_ui(self.root.read_bytes("resources/sidebar.ui"))
    self.host.register_sidebar("info", self.get_text("title"), widget)
    self.host.on("current_changed", self._on_current)

def teardown(self):
    self.host.off("current_changed")

host

Third constructor argument. The same names are also injected as builtins. Plugins do not call bind.

methodhost.register_format(extension, kind) -> None

kind is "image" / "archive". Safe in __init__.

host.register_format(".png", "image")
host.register_format(".xyz", "archive")
methodhost.register_sidebar(sidebar_id, title, widget_or_layout, aliases=None) -> None

QWidget or QLayout. The host docks it and auto-registers plugin:{plugin_id}:sidebar:{sidebar_id}. The dock title and sidebar menu use title; shortcut / gesture labels become Show/Hide {title} Sidebar. aliases are old shortcut ids. The host does not hard-code plugin-specific ids.

widget = QWidget()
host.register_sidebar("info", get_text("title"), widget)
# Public id: plugin:com.example.sidebar:sidebar:info

host.register_sidebar(
    "info",
    get_text("title"),
    widget,
    aliases=("toggle_my_dock",),
)
methodhost.unregister_sidebar(sidebar_id) -> None

Removes the sidebar and its toggle action.

host.unregister_sidebar("info")
methodhost.register_action(action_id, label, callback, aliases=None) -> None

Custom action. Public id is plugin:{plugin_id}:{action_id}. action_id cannot be sidebar or contain :. Appears in shortcut / gesture lists. No default key.

def _reload():
    self._refresh(host.get_current("folder"))

host.register_action("reload", get_text("reload"), _reload)
# Public id: plugin:com.example.sidebar:reload
methodhost.unregister_action(action_id) -> None

Drops the action. User bindings stay in config.

host.unregister_action("reload")
methodhost.register_config(key, value_type, default=None, label=None, description=None) -> None

value_type is "bool" / "string" / "int". Schema survives disable, so __init__ is fine. Adds a Settings button on the plugin row.

host.register_config(
    "fetch_web",
    "bool",
    default=True,
    label=get_text("config.fetch_web"),
    description=get_text("config.fetch_web.desc"),
)
methodhost.get_config(key, default=None) -> Any

This plugin's stored value, or the schema default. Other plugins' rows are not readable.

if host.get_config("fetch_web", True):
    self._fetch(folder)
methodhost.set_config(key, value) -> bool

Coerces, stores, and emits config_changed ({key, value}) to this plugin only.

host.set_config("fetch_web", False)
methodhost.delete_config(key) -> bool

Deletes the stored value. The schema remains.

host.delete_config("fetch_web")
methodhost.load_ui(bytes_or_path) -> QWidget

Loads a Designer .ui with QUiLoader.

widget = host.load_ui(self.root.read_bytes("resources/sidebar.ui"))
title = widget.findChild(QLabel, "titleLabel")

folder = host.get_current("folder")

methodhost.reload_current(page=None) -> bool

Reopens the current file and clears the image cache. page is 1-based. Omit it to keep the current page. Out-of-range values are clamped.

host.reload_current(3)
methodhost.on(event, callback) / host.off(event, callback=None)

current_changed and config_changed. Omitting callback on off removes all of this plugin's handlers for that event.

def _on_current(payload):
    self._refresh(payload.get("folder"))

def _on_config(payload):
    if payload.get("key") == "fetch_web":
        self._refresh(host.get_current("folder"))

host.on("current_changed", _on_current)
host.on("config_changed", _on_config)
host.off("current_changed")
methodhost.get_app_config() -> Mapping

Read-only: language / viewer / cache / ui_font.

lang = host.get_app_config().get("language")
methodhost.ask_password(file_path, mismatch=False, verify=None) -> str | None

Host password dialog, plus session and stored passwords. Safe from worker threads. None means cancel or app exit.

password = host.ask_password(
    file_path,
    verify=lambda pwd: self._can_open(file_path, pwd),
)
if password is None:
    raise RuntimeError("password cancelled")
methodhost.show_dialog(name, **kwargs) -> Any

password / archive_password / ask_password map to ask_password. Anything else logs a warning and returns None.

password = host.show_dialog("ask_password", file_path=file_path)
methodhost.run_action(action_id, **kwargs) -> bool

Runs a host action (e.g. new_tab) or a registered plugin action. Returns False if unsupported.

host.run_action("new_tab")

get_text

funcget_text(key: str, **kwargs) -> str

Lookup: plugin langs/{lang}.json → plugin ja/en → host. Plugin keys take precedence. Supports str.format(**kwargs).

langs/en.json

{
  "title": "Product info",
  "reload": "Reload",
  "status": "{count} items"
}
title = get_text("title")
status = get_text("status", count=3)

root

methodroot.read_bytes(relative_path: str) -> bytes

Read a relative path in the plugin. Missing entries raise KeyError.

ui = root.read_bytes("resources/sidebar.ui")
icon = root.read_bytes("resources/icon.png")
methodroot.exists(relative_path: str) -> bool

Whether that relative path exists in the plugin.

if root.exists("resources/sidebar.ui"):
    widget = host.load_ui(root.read_bytes("resources/sidebar.ui"))

Events

current_changed

Fired when the current file changes. Payload is {path, folder, page}.

config_changed

Fired after this plugin's set_config. Payload is {key, value}. Other plugins' changes are not delivered.

def _on_current(payload):
    print(payload["folder"], payload["page"])

def _on_config(payload):
    print(payload["key"], payload["value"])

host.on("current_changed", _on_current)
host.on("config_changed", _on_config)

Limits

  • No import ez_co and no imports from other plugins
  • Dock placement / floating is host-owned
  • Other plugins' settings are not readable (plugin_id is hashed)
  • DLL plugins are not supported
  • Restart after adding a ZIP or folder
  • If more than one plugin has the same id, choose one at startup. The choice is saved; change it later in Plugin Settings
