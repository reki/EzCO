🚀 Advanced Features

EzCo offers powerful advanced features to enhance your image viewing experience.

🎨 Customization Features

EzCo supports advanced customization through external files.

📝 Custom Fonts (font/ folder)

💡 Font Customization

Create a font/ folder in the same directory as the EzCo executable and add TTF files to use custom fonts.

1

Create Folder

Create a font folder in the same directory as EzCo.exe.

EzCo.exe font/ ├── MyFont.ttf ├── CustomUI.ttf └── JapaneseFont.ttf
2

Place Font Files

Copy TTF format font files to the font/ folder.

3

Configure Settings

Specify the font name in the settings dialog (Font) or in exported YAML under ui_font.font_family.

ui_font: font_family: "MyFont"

⚠️ Font Notes

  • Supported format: TTF (TrueType Font) only
  • Specify font name without extension (filename)
  • For Japanese fonts, choose fonts that support Japanese characters
  • Font changes are applied after restart

🌐 Custom Languages (langs/ folder)

💡 Multi-language Support

In addition to built-in Japanese and English, you can customize your own languages or text by placing JSON files in the langs/ folder.

Default behavior: If external language files don't exist or an invalid language code is specified, the built-in Japanese display is used as default.

1

Create Folder

Create a langs folder in the same directory as EzCo.exe.

EzCo.exe langs/ ├── ja.json # Japanese customization ├── en.json # English customization ├── zh.json # Chinese (new language) └── kr.json # Korean (new language)
2

Create Language File

Define language data in JSON format. Use the same structure as built-in language files.

{ "app_name": "EzCo", "language": "中文", "language_code": "zh", "ui": { "file": "文件", "edit": "编辑", "view": "查看", ... } }
3

Select Language

Specify the language filename (without extension) in the settings dialog (Language) or in exported YAML under language.code.

language: code: "zh" # Use langs/zh.json

Fallback behavior: If the specified language file doesn't exist, built-in Japanese is automatically used.

💡 Language Customization Tips

  • Partial customization: Define only the items you want to change
  • Priority:
    1. External language files (langs/ folder)
    2. Built-in language files (en.json, ja.json)
    3. Default (built-in Japanese) ※When file doesn't exist
  • System mode: When language.code: "system", automatically selects built-in language (Japanese/English) based on OS language settings
  • Character encoding: Save as UTF-8
  • Structure reference: Refer to built-in src/ez_co/resources/langs/

🔧 Customize Existing Language

When you want to change some text in Japanese or English

// langs/ja.json (partial customization example) { "ui": { "next_page": "➡️ Next", "prev_page": "⬅️ Previous" } }

🌍 Add New Language

When adding a completely new language

// langs/fr.json (French example) { "app_name": "EzCo", "language": "Français", "language_code": "fr", "ui": { "file": "Fichier", "edit": "Édition", ... } }

⚠️ Language File Notes

  • JSON syntax errors will cause loading to fail
  • Invalid language codes will fallback to system default language
  • Language changes are applied after restart
  • Don't omit required items (app_name, language_code, etc.)

📦 Archive File Support

EzCo supports a wide variety of archive formats, allowing you to directly view images inside compressed files without extracting them first.

Supported Archive Formats

📁

Standard Archives

ZIP, 7Z, RAR, TAR
Common archive formats

📚

Comic Formats

CBZ, CBR, PDF
Comic-specific archive formats and PDF

Japanese Filename Support

EzCo supports automatic encoding detection for filenames containing Japanese characters.

👆 Mouse Gestures

Mouse gestures allow you to quickly perform common actions by drawing patterns with the right mouse button. The table below is registered only when creating the first profile (or a new profile). Deleted assignments are not restored on the next start.

Gesture Action Description
← Previous Comic Move to the previous file
→ Next Comic Move to the next file
↓ Exit Application Close EzCo
↓→ Toggle Fullscreen Switch fullscreen mode ON/OFF
↑↓ Reopen last file Open the latest history item
→← / ←→ First / last page Jump to the first or last image

📑 Bookmark Features

Save your favorite pages and organize them in folders for quick access.

📌 Add Bookmark

Ctrl + Shift + B
or Features / Extensions → Add/Remove Bookmark

📂 Show Sidebar

Ctrl + B
or Features / Extensions → Bookmarks

In the sidebar, click opens the current tab, Ctrl+click or middle-click opens a new tab, and right-click lets you choose.

📚 History Features

EzCo automatically keeps track of recently viewed files and their last viewed pages.

💡 History Features

  • Automatically saves the last viewed page for each file
  • Configurable history limit (1-99 entries)
  • Quick access through the history sidebar (click = current tab, Ctrl+click or middle-click = new tab)
  • Automatic cleanup of deleted files

🔗 Virtual Path Features

Virtual paths allow you to directly reference specific files within archive files.

📋 Basic Syntax

archive://archive_file_path|internal_file_name

🖱️ Command Line Launch

EzCo.exe "archive://path|file"
