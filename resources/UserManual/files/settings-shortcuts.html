ショートカット設定

アクションの名前・ID・動作・既定割り当ては、アクションリファレンスにまとめています。

ショートカットを変更する

  1. メニューの「設定」→「ショートカット設定」を開きます。
  2. 「追加」でアクションを選び、キーボードキーまたはマウス入力を押します。
  3. 削除する場合は一覧の行を選んで「削除」を押します。
  4. OKで確定します。再起動は不要で、メニュー表示と操作へすぐ反映されます。

割り当ての規則

  • 1つのアクションへ複数の入力を割り当てられます。
  • 同じ入力を複数のアクションへ追加することはできません。
  • 既定割り当ては最初のプロファイルを作るときに入ります。メニューから追加するプロファイルは、現在の設定とプラグイン個別設定をコピーします。
  • 削除した割り当ては通常の再起動では復元されません。ただしショートカットファイルのimportでは、不足する既定アクションが補われます。

入力名

修飾キーは + で連結します。例: Ctrl+Shift+O。

種類使用できる名前
修飾キーCtrl, Alt, Shift, Meta
移動・特殊キーLeft, Right, Up, Down, Return, Escape, Space, Tab, Home, End, PageUp, PageDown
マウスMouseLeft, MouseRight, MouseMiddle, MouseWheelUp, MouseWheelDown, MouseX1, MouseX2

マウスジェスチャーを変更する

  1. メニューの「設定」→「ジェスチャー設定」を開きます。
  2. 「追加」を押し、右ボタンを押しながら方向を描きます。
  3. 割り当てるアクションを選んで確定します。

方向は ← → ↑ ↓ で表し、連続した方向も登録できます。押下と解放の両方が必要な「マウスロックの反転」はジェスチャーへ割り当てられません。

最初のプロファイルの既定ジェスチャーは、前／次コミック、終了、フルスクリーン、最後のファイル、最初／最後のページ、ページスライダーです。詳細はアクションリファレンスを参照してください。

インポート／エクスポート

ショートカット設定ダイアログは、shortcuts セクションだけをYAMLで保存します。

shortcuts:
  next_page:
    - MouseLeft
    - Right
    - Space
  hold_mouse_lock:
    - Ctrl
    - MouseMiddle

ジェスチャー設定ダイアログは、方向とアクションIDの対応をJSONで保存します。

{
  "←": "prev_comic",
  "→": "next_comic",
  "↓→": "fullscreen"
}

全般設定のエクスポートはYAMLで、上記の shortcuts と gesture_map を他の設定と一緒に含みます。
