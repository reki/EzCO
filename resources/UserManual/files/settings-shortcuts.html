⌨️ ショートカット設定 (shortcuts)

キーボードキーとマウスボタンによるショートカットを設定します。

⚠️ ショートカット設定の注意点

  • 各アクションには複数のショートカットを配列で設定できます
  • 修飾キー（Ctrl、Alt、Shift）は「+」で連結します
  • マウスボタンとキーボードキーを混在させることができます
  • デフォルト割り当ては、プロファイルが無い初回起動（または新規プロファイル作成）のときだけ入ります。消した割り当ては再起動しても戻りません
  • 設定変更後は、EzCoを再起動する必要があります

👆 ジェスチャー設定 (gesture_map)

マウスの右ボタンドラッグによるジェスチャー機能を設定します。下の割り当ては初回プロファイル作成時のデフォルトです。消したジェスチャーは再起動しても戻りません。

🖱️ ジェスチャーの使い方

右ボタンを押しながらマウスを動かすことで、設定されたアクションを実行できます。複数の方向を組み合わせた複合ジェスチャーも設定可能です。

←前のコミック
gesture_map."←"
左方向のスワイプ → prev_comic
→次のコミック
gesture_map."→"
右方向のスワイプ → next_comic
↓アプリを閉じる
gesture_map."↓"
下方向のスワイプ → close_app
↓→フルスクリーン
gesture_map."↓→"
下→右の複合ジェスチャー → fullscreen
↑↓前回のファイル
gesture_map."↑↓"
上→下の複合ジェスチャー → reopen_last_file
→←最初のページ
gesture_map."→←"
右→左の複合ジェスチャー → first_page
←→最後のページ
gesture_map."←→"
左→右の複合ジェスチャー → last_page
↓→←ページスライダー
gesture_map."↓→←"
下→右→左の複合ジェスチャー → page_slider_dialog

💡 ジェスチャーのコツ

  • 方向記号: ← (左) → (右) ↑ (上) ↓ (下)
  • 複合ジェスチャー: 方向を連続して組み合わせることで、より多くのアクションを設定可能
  • 認識精度: ゆっくりと明確に方向を描くと認識精度が向上します
  • カスタマイズ: 任意のアクションに任意のジェスチャーを割り当てることができます
gesture_map: # 基本ジェスチャー（単一方向） "←": "prev_comic" # 左スワイプ → 前のコミック "→": "next_comic" # 右スワイプ → 次のコミック "↓": "close_app" # 下スワイプ → アプリを閉じる # 複合ジェスチャー（2方向） "↓→": "fullscreen" # 下→右 → フルスクリーン "↑↓": "reopen_last_file" # 上→下 → 前回のファイル "→←": "first_page" # 右→左 → 最初のページ "←→": "last_page" # 左→右 → 最後のページ # 複合ジェスチャー（3方向） "↓→←": "page_slider_dialog" # 下→右→左 → ページスライダー # カスタムジェスチャーの例 "↑": "zoom_in" # 上スワイプ → 拡大 "↑→": "rotate_right" # 上→右 → 右回転 "↑←": "rotate_left" # 上→左 → 左回転
