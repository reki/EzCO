Action Reference

These built-in actions are offered by Shortcut Settings and Mouse Gesture Settings. “None” means no input is assigned initially. In “Available in,” “Both” means the action can be configured as either a shortcut or gesture; “Shortcut only” means keyboard or mouse inputs only.

Default key conflicts

Ctrl+0 is assigned to Reset Zoom and Last Tab, while Ctrl+T is assigned to Always on Top and New Tab. Tab actions currently take priority. Ctrl+O conflicts between the non-configurable Open File command and Rotate Left.

Plugin Actions

Actions registered by enabled plugins are added to the settings picker at runtime. See each plugin for its labels and behavior. A plugin alias can replace a built-in ID in the picker.
