📚 EzCoについて

🖼️

画像ビューア

PNG、JPG、GIF、BMP、TIFF、WebPなど、主要な画像形式に対応。画像ファイルやフォルダを直接開けます。

📦

アーカイブ対応

ZIP、7Z、RAR、CBZ、CBR、TAR、PDFなど、様々なアーカイブ形式を直接開けます。

👆

マウスジェスチャー

右クリックドラッグでアプリケーションを直感的に操作できます。

⚡

高速表示

プリフェッチ機能により、ページめくりを高速化します。

📖

両開き表示

単ページ、両開き（右）、両開き（左）をメニューから切り替えられます。見開き単位でページ送りします。

👤

プロファイル

設定・ブックマーク・履歴を用途別に分けて管理できます。メニューから追加・切替・管理が可能です。

🗂️

タブ

複数ファイルを同時に開けます。中央クリックでタブを閉じ、Ctrl+1〜9 で切り替えられます。

📑

ブックマーク

お気に入りのページをブックマークして素早くアクセスできます。

🌐

多言語対応

日本語と英語に対応し、カスタム言語ファイルも追加できます。外部言語ファイルで未定義のキーはキー名が表示されます。

💡 EzCoの特徴

  • 軽量・高速： 最小限のリソースで高速な画像表示を実現
  • 豊富な形式対応： 画像ファイルからアーカイブファイルまで幅広くサポート
  • カスタマイズ可能： ショートカット、ジェスチャー、見た目などを自由に設定
  • コミックビューア： 漫画や電子書籍の閲覧に最適化

⬇️ インストール

EzCoは実行ファイル形式で配布されており、インストール不要で使用できます。

1

ダウンロード

リリースページから最新版のEzCo.exeをダウンロードします。

2

配置

任意のフォルダにEzCo.exeを配置します。

3

実行

EzCo.exeをダブルクリックして起動します。

⚠️ 注意事項

  • 初回起動時に設定・ブックマーク・履歴をまとめたデータベース（config.db）が自動作成されます。旧バージョンのbookmarks.dbだけがある場合はconfig.dbへリネームされます
  • Windows Defenderが警告を表示する場合がありますが、実行許可してください
  • 動作にはWindows 10以降が必要です

🎮 基本操作

ファイルを開く

📁 メニューから開く

ファイル → ファイルを開く / 新しいタブでファイルを開く / フォルダを開く。

🖱️ ドラッグ&ドロップ

ファイルやフォルダ、状態ファイル（.ezs）をウィンドウにドロップして開けます。

⌨️ ショートカット

Ctrl + Oでファイル選択。フォルダを開くはショートカット設定から割り当てできます。

🔗 ファイル関連付け

画像ファイルをEzCoに関連付けることでダブルクリックで開けます。

💡 ファイルダイアログ

先頭の「対応しているファイル」に、画像・アーカイブ・読み込み済みプラグインの拡張子・状態ファイルがまとめて出ます。続けて画像／アーカイブ／プラグイン形式／状態ファイル／すべてのファイルを選べます。

複数のパスを開く／ドロップしたときは、プラグイン設定の種別で画像を1タブのページとしてまとめます。アーカイブやフォルダを別タブにするかは、設定のタブ設定で選べます（既定はアーカイブだけ別タブ）。タブの並びは選択／ドロップ順です。

状態の保存と復元

開いているタブのファイル（またはフォルダ）とページを、状態ファイル（.ezs）に保存できます。空のタブは保存しません。

操作 方法（デフォルト） 説明
状態を名前をつけて保存 ファイルメニュー、Ctrl + S（初回） 全タブのパスとページ、今のタブ位置を保存
状態を復元 ファイルを開く／D&D .ezsを開くとタブを復元

💡 すでにファイルを開いているとき

  • すべて閉じる: 今のタブを閉じて、保存した状態だけを開く
  • 開いているタブに追加: 今のタブはそのまま、後ろに復元タブを足す
  • 新規ウィンドウで表示: 今のウィンドウはそのまま、新しいウィンドウで復元する
  • キャンセル: 何も変えない

空のウィンドウでは確認せず、そのまま復元します。見つからないファイルのタブはエラー表示になり、見つかった分は開きます。

コミック表示（両開き）

メニューバーのコミック（表示の右隣）から、ページの並べ方を切り替えられます。選択は現在のプロファイルに保存されます。

モード 並び 説明
単ページ 1ページずつ 通常の1枚表示です。
両開き（右） 右が軸 N、左が N+1 右綴じ向け。スライダーは右が先頭です。
両開き（左） 左が軸 N、右が N+1 左綴じ向け。スライダーは左が先頭です。

💡 両開きの動作

  • ページ送り: 次/前は見開き単位（2ページ）です。最終奇数ページのみ単ページ表示になります
  • 選択ページを軸: 設定で有効にすると、スライダーで選んだページが見開きの先頭（N）になります。2ページ目から前に戻ると、1ページ目だけ単ページになることがあります
  • スライダー方向: 単ページと両開き（右）は右が先頭。両開き（左）のみ左が先頭です
  • 切替の優先: 設定ダイアログの全般→ビューアで「前回の選択を維持」「右を優先」「左を優先」を選べます
  • ショートカット: 単ページ／両開き（右）／両開き（左）／両開き切替は初期未割り当てです。ショートカット設定から割り当てできます

フィルター

メニューバーのフィルター（機能／拡張とプロファイルの間）から、表示中の画像だけを補正します。サムネイルと画像リストは原画のままです。有効にした順に適用し、現在のプロファイルへ保存されます。

項目 説明
基本補正 明るさ・コントラスト・ガンマ・グレースケール。設定は1つのダイアログです。初期化で既定値に戻せます
プラグインのフィルター プラグインが ON で register_filter したときだけ出ます。設定はプラグイン設定と同じダイアログです
有効 表示画像の pipe に入れます。プラグイン自体の ON/OFF とは別です
設定 pipe に入っているときだけ見た目に即反映します。先に有効にしてください

💡 プラグイン ON とフィルター

  • プラグインを OFF にしても、フィルターの有効記憶（pipe）は残ります。再び ON すれば同じ順で戻ります
  • 拡張子やサイドバーだけ使いたいときは、プラグインは ON のまま、フィルターの有効だけ外してください

タブ

メニューバーのタブ（コミックの右隣）から、新規・閉じる・再表示・左右／先頭／末尾への移動ができます。割り当て済みのキーボードショートカットは、メニュー項目の右側に表示されます。

操作 方法（デフォルト） 説明
新しいタブ Ctrl + T 空のタブを追加
タブを閉じる Ctrl + W、タブの中央クリック 今のタブ（またはクリックしたタブ）を閉じる。最後の1枚を閉じるとウィンドウも閉じます
タブの再表示 Ctrl + Shift + T 直前に閉じたタブを戻す。戻せるタブが無いときはメニューを無効化
左右のタブ Ctrl + PageUp / Ctrl + PageDown 左／右のタブへ移動
1〜9番目／最後 Ctrl + 1〜9、Ctrl + 0 / Ctrl + End 番号のタブ、または最後のタブを表示。メニュー項目はなし

💡 タブの動作

  • タブバー: 2枚以上のときだけ表示。幅は固定で、長い名前は省略し、マウスを乗せると全文が出ます
  • タブ一覧: 機能／拡張 → サイドバー → タブ一覧。クリックで切替、中央クリックまたは右クリックで閉じる
  • フルスクリーン: 表示 → フルスクリーン時にタブを表示で、フルスクリーン中もタブバーを出すか選べます
  • 開く: 「ファイルを開く」「フォルダを開く」は今のタブ。「新しいタブでファイルを開く」は新規。複数の画像は1タブのページ。アーカイブ／フォルダの別タブは設定で切替。履歴とブックマークはクリック＝今のタブ、Ctrl+クリックまたは中央クリック＝新規タブ
  • 復元: 再起動ではタブ全部は戻しません。履歴の最後の1件だけを開く設定があります。複数タブは「状態を名前をつけて保存」で戻せます

⚙️ コマンドライン引数

EzCoは起動時にコマンドライン引数を使用して、一時的に設定を変更することができます。この機能により、設定ファイルを変更することなく、起動時のみ特定の設定を有効にできます。

基本的な使用方法

EzCo.exe --conf:section.key=value --profile=profile_name

💡 特徴

  • 一時的な変更： 設定ファイルは変更されず、起動中のみ有効
  • UI非活性化： オーバーライドされた設定項目は設定画面とメニューで非活性化
  • 複数指定可能： 複数の設定を同時にオーバーライド可能
  • 型自動変換： ブール値、数値、文字列を自動で判別

使用例

📦 アーカイブ機能を無効化

EzCo.exe --conf:archive.enabled=False

起動中のみアーカイブファイルを開けなくします。

🖼️ ウィンドウ自動リサイズを有効化

EzCo.exe --conf:window.auto_resize=True

画像読み込み時にウィンドウサイズを自動調整します。

🐛 デバッグモードを有効化

EzCo.exe --conf:debug.enabled=True

デバッグログファイルを出力します。

🔧 複数設定の同時指定

EzCo.exe --conf:archive.enabled=False --conf:window.auto_resize=True --conf:debug.enabled=True

複数の設定を同時にオーバーライドできます。

👤 プロファイル指定

EzCo.exe --profile=仕事用

存在するプロファイルを指定して、そのセッションだけ使用します（-p 名前も可）。存在しない場合は作成せず、前回使ったプロファイルで起動します。前回の選択は書き換えません。

🔗 プロファイルと設定の組み合わせ

EzCo.exe --profile=デバッグ --conf:debug.enabled=True

プロファイル指定と設定オーバーライドを同時に使用できます。

プロファイル機能

👤 プロファイルとは

プロファイル機能を使用することで、異なる用途（仕事用、プライベート用など）に応じて、設定・履歴・ブックマークをまとめて分けて管理できます。操作はメニューバーのプロファイルから行います（設定ダイアログにはプロファイルタブはありません）。

📁

独立したデータ

各プロファイルは独自の設定・履歴・ブックマークを持ち、相互に影響しません。

⚡

簡単切り替え

メニューからプロファイルを選ぶと、両開き・背景・言語・ショートカットなどがすぐに反映されます。

🚀

起動時指定

コマンドライン引数で、そのセッションだけプロファイルを指定できます。

🔧

管理

メニューから追加・改名・削除できます。追加時は今の設定（プラグイン選択を含む）をコピーし、履歴とブックマークは空です。既定プロファイルは削除できません。CLIで存在しない名前を指定しても作成しません。

プロファイル使用例

コマンド 説明
EzCo.exe --profile=仕事 「仕事」プロファイルで起動
EzCo.exe --profile=プライベート 「プライベート」プロファイルで起動
EzCo.exe --profile=研究資料 「研究資料」プロファイルで起動
※ 存在しない場合は前回のプロファイルを使用

設定可能な主要項目

設定項目 例 説明
archive.enabled --conf:archive.enabled=False アーカイブファイルサポートの有効/無効
window.auto_resize --conf:window.auto_resize=True 画像読み込み時のウィンドウ自動リサイズ
window.always_on_top --conf:window.always_on_top=True ウィンドウを常に手前に表示
viewer.fit_to_window_minimum --conf:viewer.fit_to_window_minimum=False 最小縮小率の制限（100%まで）
viewer.mouse_lock --conf:viewer.mouse_lock=True マウスロック機能
debug.enabled --conf:debug.enabled=True デバッグモード
language.code --conf:language.code=en 言語設定（ja/en/system）

値の型

型 指定可能な値 例
ブール値 True, False, yes, no, on, off, 1, 0 --conf:debug.enabled=True
数値 整数または小数 --conf:cache.prefetch_pages=10
文字列 任意のテキスト --conf:language.code=en

⚠️ 注意事項

  • オーバーライドされた設定項目は、設定画面やメニューで非活性化（グレーアウト）されます
  • 設定データベース（config.db）の永続値は変更されません。永続的な変更は設定画面から行ってください
  • ジェスチャーやショートカットの設定は、コマンドライン引数では変更できません
  • 存在しない設定項目を指定した場合は無視されます
