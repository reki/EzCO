📚 About EzCo

🖼️

Image Viewer

A viewer that supports major image formats including PNG, JPG, GIF, BMP, TIFF, and WebP. Can directly open image files and folders.

📦

Archive Support

Directly open various archive formats including ZIP, 7Z, RAR, CBZ, CBR, TAR, and PDF.

👆

Mouse Gestures

Control the application intuitively with right-click drag gestures.

⚡

High-Speed Display

Prefetch functionality accelerates page turning for smooth reading.

📖

Spread View

Switch single page, spread (right), or spread (left) from the View menu. Page turning moves two pages at a time.

👤

Profiles

Keep settings, bookmarks, and history separate by purpose. Add, switch, and manage from the Profile menu.

🗂️

Tabs

Open multiple files at once. Middle-click closes a tab. Ctrl+1–9 switches tabs.

📑

Bookmarks

Bookmark favorite pages for quick access later.

🌐

Multi-language Support

Supports Japanese and English, with the ability to add custom language files. Undefined keys in external language files display the key name.

🔌

Plugins

ZIP or folder plugins can add formats, filters, sidebars, and actions.

💡 EzCo Features

  • Lightweight & Fast: High-speed image display with minimal resource usage
  • Wide Format Support: Supports everything from image files to archive files
  • Highly Customizable: Freely configure shortcuts, gestures, appearance, and more
  • Comic Viewer: Optimized for reading manga and electronic books

⬇️ Installation

EzCo is distributed as an executable file and can be used without installation.

1

Download

Download the latest version of EzCo.exe from the release page.

2

Placement

Place EzCo.exe in any folder of your choice.

3

Execution

Double-click EzCo.exe to launch the application.

⚠️ Important Notes

  • On first launch, a database (config.db) is created for settings, bookmarks, and history. If only a legacy bookmarks.db exists, it is renamed to config.db
  • Windows Defender may display warnings, but please allow execution
  • Requires Windows 10 or later to run

🎮 Basic Usage

Opening Files

📁 Open from Menu

File → Open File / Open File in New Tab / Open Folder.

🖱️ Drag & Drop

Drop files, folders, or state files (.ezs) onto the window. Files and folders open in the tab under the drop. A tab on the bar opens that tab. Empty bar space, or the area outside the panes, keeps the current tab. When the setting opens a new tab, it is added to that pane's tab bar. A state file restores the window and does not pick a tab by position.

⌨️ Shortcut

Ctrl + O opens the file dialog. Assign a shortcut to Open Folder in Shortcut Settings if you want one.

🔗 File Association

Associate image files with EzCo to open them with a double-click.

💡 File Dialog

The first filter, Supported Files, lists images, archives, loaded plugin extensions, and state files. You can then choose Images, Archives, Plugin formats, State Files, or All Files.

When you open or drop multiple paths, images (by Plugin Settings kind) become pages in one tab. Whether archives and folders open in their own tabs is set under Tab Settings (archives do by default). Tab order follows the selection or drop order.

Save and Restore State

Save the file (or folder), page, and pinned state of every open tab to a state file (.ezs). Empty tabs are not saved. Tabs in an older state file with no pinned flag open unpinned.

Action Method (Default) Description
Save State As... File menu, Ctrl + S (first profile) Saves every tab path, page, and pinned state, plus the current tab
Restore state Open File / drag and drop Opening a .ezs restores the tabs

💡 If files are already open

  • Close All: Close current tabs and restore only the saved state
  • Add to Open Tabs: Keep current tabs and append the restored tabs
  • Open in New Window: Leave this window as-is and restore in a new window
  • Cancel: Change nothing

An empty window restores immediately. Missing files become error tabs; files that still exist open normally. After restore, pinned tabs sit to the left of unpinned tabs. Adding to open tabs regroups the whole window the same way. The tab that was current stays current even if its index changes.

Page Navigation

⚙️ Shortcut Customization

All basic operation keyboard shortcuts and mouse actions can be freely changed in Settings → Shortcut Settings.

Action Method (Default) Description
Next Page →, Space, Left Click Display the next image
Previous Page ←, V, Right Click Display the previous image
Next File Ctrl + → Move to the next file
Previous File Ctrl + ← Move to the previous file
First Page Gesture: →← Return to the first image
Last Page Gesture: ←→ Move to the last image

Zoom Features

Action Method Description
Zoom In Wheel Down Enlarge the image
Zoom Out Wheel Up Reduce the image
Reset Zoom Ctrl + 0 Reset zoom level to 100%
Move Image Left Drag (when zoomed) Move the enlarged image

Reading-order navigation while zoomed: Choose a mode under View → Zoomed Navigation. Turn Page First keeps the previous behavior and turns the page immediately. Pan Left First moves one screen at a time from the upper right toward the left, while Pan Right First starts at the upper left and moves right. At a horizontal edge, navigation continues on the next row; at the image edge, it turns the page. Previous-page navigation follows the same route in reverse. Images that overflow on only one axis move to that axis's edge. Spread view treats the combined spread as one image.

Invert Mouse Lock: By default, hold Ctrl or the middle mouse button to invert the current lock state. When unlocked, this hides and recenters the pointer so a screen edge cannot stop zoomed-image panning. During persistent or fullscreen lock, it temporarily unlocks the pointer. Releasing the last held input restores the previous state. Assignments can be changed in Shortcut Settings.

Image Rotation

Action Method Description
Rotate Right Ctrl + R Rotate the image 90 degrees clockwise
Rotate Left Ctrl + L Rotate the image 90 degrees counterclockwise

Comic View (Spread)

Use the View menu to change how pages are arranged. The choice is saved in the current profile.

Mode Layout Description
Single page One page at a time Standard single-image view.
Spread (right) Right is axis N, left is N+1 For right-bound books. The slider starts from the right.
Spread (left) Left is axis N, right is N+1 For left-bound books. The slider starts from the left.

💡 Spread Behavior

  • Page turning: Next/previous moves two pages. The last odd page is shown alone
  • Selected page as axis: When enabled, the slider-selected page becomes the first page (N) of the spread. Going back from page 2 may show page 1 alone
  • Slider direction: Right is first for single page and spread (right). Left is first only for spread (left)
  • Toggle preference: In Settings → General → Viewer, choose Keep previous, Prefer right, or Prefer left
  • Shortcuts: Single / Spread (right) / Spread (left) / Toggle spread are unassigned by default. Assign them in Shortcut Settings

Filters

The Filter menu (next to View) adjusts only the image on screen. Thumbnails and the image list stay original. Filters apply in the order you enable them and are saved in the current profile.

Item Description
Basic adjustment Brightness, contrast, gamma, grayscale in one dialog. Reset restores the defaults
Plugin filters Shown only while the plugin is on and called register_filter. Settings use the same dialog as Plugin Settings
Enabled Puts the filter in the display pipe. This is not the plugin's own on/off
Settings Live preview only when the filter is in the pipe. Enable it first to see changes

💡 Plugin on vs filter pipe

  • Turning a plugin off keeps the filter enable list (pipe). Turning it back on restores the same order
  • To keep extensions or a sidebar without altering the picture, leave the plugin on and uncheck Enabled on the filter

Tabs

The Tab menu (next to Filter) has New, Close, Reopen, and move left / right / first / last. Assigned keyboard shortcuts appear on the right of matching menu items.

Action Method (Default) Description
New tab Ctrl + T Add an empty tab
Close tab Ctrl + W, middle-click a tab Close the current tab (or the clicked tab). Closing the last tab closes the window
Reopen tab Ctrl + Shift + T Restore the last closed tab. The menu item is disabled when there is nothing to restore
Left / right tab Ctrl + PageUp / Ctrl + PageDown Move to the left or right tab
1st–9th / last Ctrl + 1–9, Ctrl + 0 / Ctrl + End Show that tab. These are shortcuts only (no menu items for 1–9)
Split right / split down Ctrl + Shift + Right / Ctrl + Shift + Down Shows the next tab that is not selected in any pane, to the right of or below the last operated tab. Dropping a tab on the image moves it to the tab bar in that direction from the center. At most four panes are visible
Split into four / single view Ctrl + Shift + Up / Ctrl + Shift + Left Lays out up to four tabs from the last operated tab. Single view keeps that tab and hides the other panes without closing tabs

💡 Tab Behavior

  • Tab bar: With one pane, the bar is shown only when that pane has two or more tabs. While split, each pane has its own bar at the top, listing only that pane's tabs, even when the pane has one tab. Dropping a tab on another pane's bar moves it. An empty pane collapses. Tabs are not copied. Unpinned tabs have a fixed width; long names are elided and the full name appears on hover
  • Split: Until you split, one pane is shown. Dropping a tab on the image moves it to the tab bar in that direction from the center of the pane. If a pane is already there, the tab is added to that bar. A new pane is created only when there is no pane in that direction. If the dragged tab was showing, the tab to its left stays selected in the original pane, or the tab to its right when there is no tab on the left. If there is no partner and the original pane is empty, that pane collapses. Clicking a tab makes it current. A gesture selects the tab where it started, inside that pane. Shortcuts such as Close act on the tab that was last operated on, including Open. Split right, split down, and split into four use the next tab, in order across panes, that is not selected in any pane. While a tab bar is shown, the current tab uses the configured color even when the view is not split. When the gradient is on, the left uses the configured opacity and the right is clear. One tab is never shown in two panes
  • Tab list: Extensions → Sidebar → Tab List. Click to switch; middle-click to close
  • Right-click: The tab bar and the tab list show the same menu: close this tab, close other tabs, close tabs to the right, close tabs to the left, pin or unpin, duplicate, copy file name, and copy full path. Close others, close left, and close right leave pinned tabs open. Those items are disabled when there is no unpinned tab to close. Copy is disabled on an empty tab. A right-click on the tab bar opens the menu only and does not run the action assigned to the right mouse button. A pinned tab moves to the left, becomes narrower, and loses its close button. Pinning or unpinning leaves the current tab selected when it is a different tab. Middle-click and Close Tab still close it. Dragging stays inside the pinned group or the unpinned group. Duplicate opens the same file and page in a new tab. An empty tab duplicates as another empty tab
  • Page slider: Extensions → Page Slider. Docks at the bottom by default. While docked, the title bar is hidden and Float and Close sit at the right of the controls. Undocking makes a floating window. It can dock only at the top or bottom. When left or right sidebars are open, it uses the remaining width. It stays open and follows the current tab. On an empty tab it cannot be used
  • Fullscreen: View → Don't Hide Tabs in Fullscreen keeps every tab bar. Don't Hide Page Slider in Fullscreen keeps the page slider. The slider cannot be used with the mouse in fullscreen. Leaving fullscreen restores the docks and maximized state from before entering
  • Open: Open File and Open Folder use the current tab. Open File in New Tab creates tabs. Multiple images become pages in one tab. Archive and folder own-tab behavior is a setting. History and bookmarks: click = current tab; Ctrl+click or middle-click = new tab
  • Restore: Restart does not restore every tab. An option can reopen only the latest history item. Use Save State As... to restore multiple tabs later

⚙️ Command-Line Arguments

EzCo allows you to temporarily modify settings at startup using command-line arguments. This feature enables you to activate specific settings for a single session without permanently changing the configuration file.

Basic Usage

EzCo.exe --conf:section.key=value --profile=profile_name

Pass a normal file or folder path, such as EzCo.exe "C:\path\to\book.cbz", to open it at startup.

💡 Features

  • Temporary Changes: Configuration file remains unchanged, effective only during startup
  • UI Deactivation: Overridden settings are disabled in settings screens and menus
  • Multiple Settings: Specify multiple settings simultaneously
  • Automatic Type Conversion: Automatically detects boolean, numeric, and string values

Usage Examples

📦 Disable Archive Support

EzCo.exe --conf:archive.enabled=False

Prevents opening archive files during this session only.

🖼️ Enable Auto Window Resize

EzCo.exe --conf:window.auto_resize=True

Automatically adjusts window size when loading images.

🐛 Enable Debug Mode

EzCo.exe --conf:debug.enabled=True

Outputs debug log files for this session.

🔧 Multiple Settings

EzCo.exe --conf:archive.enabled=False --conf:window.auto_resize=True --conf:debug.enabled=True

Override multiple settings simultaneously.

👤 Profile Specification

EzCo.exe --profile=Work

Use an existing profile for this session only (-p name also works). If it does not exist, nothing is created and the last used profile is used instead. The last selection is not overwritten.

🔗 Profile and Settings Combination

EzCo.exe --profile=Debug --conf:debug.enabled=True

Combine profile specification with setting overrides.

Profile Feature

👤 What is a Profile?

Profiles keep settings, history, and bookmarks separate by purpose (work, personal, and so on). Manage them from the Profile menu (there is no Profile tab in the settings dialog).

📁

Independent Data

Each profile has its own settings, bookmarks, and history that don't affect each other.

⚡

Easy Switching

Choosing a profile from the menu immediately applies spread mode, background, language, shortcuts, and more.

🚀

Startup Specification

Specify a profile for the current session via command-line arguments.

🔧

Management

Add, rename, or delete from the menu. Add copies the current settings (including plugin handlers); bookmarks and history stay empty. The default profile cannot be deleted. A missing CLI name is not created.

Profile Usage Examples

Command Description
EzCo.exe --profile=Work Launch with "Work" profile
EzCo.exe --profile=Personal Launch with "Personal" profile
EzCo.exe --profile="Research Materials" Launch with "Research Materials" profile
※ Uses the last profile if it does not exist

Main Configurable Settings

Setting Example Description
archive.enabled --conf:archive.enabled=False Enable/disable archive file support
window.auto_resize --conf:window.auto_resize=True Auto-resize window when loading images
window.always_on_top --conf:window.always_on_top=True Keep window always on top
viewer.fit_to_window_minimum --conf:viewer.fit_to_window_minimum=False Minimum scale restriction (up to 100%)
viewer.mouse_lock --conf:viewer.mouse_lock=True Mouse lock functionality
debug.enabled --conf:debug.enabled=True Debug mode
language.code --conf:language.code=en Language setting (ja/en/system)

Value Types

Type Acceptable Values Example
Boolean True, False, yes, no, on, off, 1, 0 --conf:debug.enabled=True
Numeric Integer or decimal numbers --conf:cache.prefetch_pages=10
String Any text --conf:language.code=en

⚠️ Important Notes

  • Overridden settings are disabled (grayed out) in settings screens and menus
  • Persistent values in the settings database (config.db) are not modified. Use the settings screen for permanent changes
  • Gesture and shortcut settings cannot be changed via command-line arguments
  • Non-existent setting items are ignored if specified

🔧 Troubleshooting

Debug Mode

Enable debug mode to generate detailed logs for troubleshooting issues.

1

Enable Debug Mode

Go to Settings → Settings → Debug Settings and check "Debug Mode".

2

Restart Application

Close and restart EzCo to begin logging.

3

Check Logs

Debug logs are saved in the logs folder with timestamps.

Common Issues

🚫 Archive Files Won't Open

Check Settings → Plugin Settings and make sure the extension is not set to Don't load.

🔤 Garbled Text in Archives

EzCo automatically detects encoding, but some files may not display correctly due to encoding issues.

Configuration Files

📁 Important Files and Folders

  • config.db: Database for per-profile settings, bookmarks, and history
  • langs/: Custom language files in the configured data location (undefined keys show key names)
  • font/: Custom TTF/OTF fonts in the configured data location
  • logs/: Debug log files (when debug mode is enabled)
