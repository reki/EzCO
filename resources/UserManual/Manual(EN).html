📚 About EzCo

🖼️

Image Viewer

A viewer that supports major image formats including PNG, JPG, GIF, BMP, TIFF, and WebP. Can directly open image files and folders.

📦

Archive Support

Directly open various archive formats including ZIP, 7Z, RAR, CBZ, CBR, TAR, and PDF.

👆

Mouse Gestures

Control the application intuitively with right-click drag gestures.

⚡

High-Speed Display

Prefetch functionality accelerates page turning for smooth reading.

📖

Spread View

Switch single page, spread (right), or spread (left) from the Comic menu. Page turning moves two pages at a time.

👤

Profiles

Keep settings, bookmarks, and history separate by purpose. Add, switch, and manage from the Profile menu.

🗂️

Tabs

Open multiple files at once. Middle-click closes a tab. Ctrl+1–9 switches tabs.

📑

Bookmarks

Bookmark favorite pages for quick access later.

🌐

Multi-language Support

Supports Japanese and English, with the ability to add custom language files. Undefined keys in external language files display the key name.

💡 EzCo Features

  • Lightweight & Fast: High-speed image display with minimal resource usage
  • Wide Format Support: Supports everything from image files to archive files
  • Highly Customizable: Freely configure shortcuts, gestures, appearance, and more
  • Comic Viewer: Optimized for reading manga and electronic books

⬇️ Installation

EzCo is distributed as an executable file and can be used without installation.

1

Download

Download the latest version of EzCo.exe from the release page.

2

Placement

Place EzCo.exe in any folder of your choice.

3

Execution

Double-click EzCo.exe to launch the application.

⚠️ Important Notes

  • On first launch, a database (config.db) is created for settings, bookmarks, and history. If only a legacy bookmarks.db exists, it is renamed to config.db
  • Windows Defender may display warnings, but please allow execution
  • Requires Windows 10 or later to run

🎮 Basic Usage

Opening Files

📁 Open from Menu

File → Open File / Open File in New Tab / Open Folder.

🖱️ Drag & Drop

Drop files, folders, or state files (.ezs) onto the window.

⌨️ Shortcut

Ctrl + O opens the file dialog. Assign a shortcut to Open Folder in Shortcut Settings if you want one.

🔗 File Association

Associate image files with EzCo to open them with a double-click.

💡 File Dialog

The first filter, Supported Files, lists images, archives, loaded plugin extensions, and state files. You can then choose Images, Archives, Plugin formats, State Files, or All Files.

Save and Restore State

Save the file (or folder) and page of every open tab to a state file (.ezs). Empty tabs are not saved.

Action Method (Default) Description
Save State As... File menu, Ctrl + S (first profile) Saves every tab path and page, plus the current tab
Restore state Open File / drag and drop Opening a .ezs restores the tabs

💡 If files are already open

  • Close All: Close current tabs and restore only the saved state
  • Add to Open Tabs: Keep current tabs and append the restored tabs
  • Open in New Window: Leave this window as-is and restore in a new window
  • Cancel: Change nothing

An empty window restores immediately. Missing files become error tabs; files that still exist open normally.

Page Navigation

⚙️ Shortcut Customization

All basic operation keyboard shortcuts and mouse actions can be freely changed in Settings → Shortcut Settings.

Action Method (Default) Description

Previous Page ←, V, Right Click Display the previous image
Next File Ctrl + → Move to the next file
Previous File Ctrl + ← Move to the previous file
First Page Gesture: →← Return to the first image
Last Page Gesture: ←→ Move to the last image

Zoom Features

Action Method Description
Zoom In Wheel Down Enlarge the image
Zoom Out Wheel Up Reduce the image
Reset Zoom Ctrl + 0 Reset zoom level to 100%
Move Image Left Drag (when zoomed) Move the enlarged image

Image Rotation

Action Method Description
Rotate Right Ctrl + R Rotate the image 90 degrees clockwise
Rotate Left Ctrl + L Rotate the image 90 degrees counterclockwise

Comic View (Spread)

Use the Comic menu (next to View) to change how pages are arranged. The choice is saved in the current profile.

Mode Layout Description
Single page One page at a time Standard single-image view.
Spread (right) Right is axis N, left is N+1 For right-bound books. The slider starts from the right.
Spread (left) Left is axis N, right is N+1 For left-bound books. The slider starts from the left.

💡 Spread Behavior

  • Page turning: Next/previous moves two pages. The last odd page is shown alone
  • Selected page as axis: When enabled, the slider-selected page becomes the first page (N) of the spread. Going back from page 2 may show page 1 alone
  • Slider direction: Right is first for single page and spread (right). Left is first only for spread (left)
  • Toggle preference: In Settings → General → Viewer, choose Keep previous, Prefer right, or Prefer left
  • Shortcuts: Single / Spread (right) / Spread (left) / Toggle spread are unassigned by default. Assign them in Shortcut Settings

Tabs

The Tab menu (next to Comic) has New, Close, Reopen, and move left / right / first / last. Assigned keyboard shortcuts appear on the right of matching menu items.

Action Method (Default) Description
New tab Ctrl + T Add an empty tab
Close tab Ctrl + W, middle-click a tab Close the current tab (or the clicked tab). Closing the last tab closes the window
Reopen tab Ctrl + Shift + T Restore the last closed tab. The menu item is disabled when there is nothing to restore
Left / right tab Ctrl + PageUp / Ctrl + PageDown Move to the left or right tab
1st–9th / last Ctrl + 1–9, Ctrl + 0 / Ctrl + End Show that tab. These are shortcuts only (no menu items for 1–9)

💡 Tab Behavior

  • Tab bar: Shown only with two or more tabs. Width is fixed; long names are elided and the full name appears on hover
  • Tab list: Extensions → Sidebar → Tab List. Click to switch; middle-click or right-click to close
  • Fullscreen: View → Show Tabs in Fullscreen keeps the tab bar visible while fullscreen
  • Open: Open File and Open Folder use the current tab. Open File in New Tab creates tabs. History and bookmarks: click = current tab; Ctrl+click or middle-click = new tab
  • Restore: Restart does not restore every tab. An option can reopen only the latest history item. Use Save State As... to restore multiple tabs later

⚙️ Command-Line Arguments

EzCo allows you to temporarily modify settings at startup using command-line arguments. This feature enables you to activate specific settings for a single session without permanently changing the configuration file.

Basic Usage

EzCo.exe --conf:section.key=value --profile=profile_name

💡 Features

  • Temporary Changes: Configuration file remains unchanged, effective only during startup
  • UI Deactivation: Overridden settings are disabled in settings screens and menus
  • Multiple Settings: Specify multiple settings simultaneously
  • Automatic Type Conversion: Automatically detects boolean, numeric, and string values

Usage Examples

📦 Disable Archive Support

EzCo.exe --conf:archive.enabled=False

Prevents opening archive files during this session only.

🖼️ Enable Auto Window Resize

EzCo.exe --conf:window.auto_resize=True

Automatically adjusts window size when loading images.

🐛 Enable Debug Mode

EzCo.exe --conf:debug.enabled=True

Outputs debug log files for this session.

🔧 Multiple Settings

EzCo.exe --conf:archive.enabled=False --conf:window.auto_resize=True --conf:debug.enabled=True

Override multiple settings simultaneously.

👤 Profile Specification

EzCo.exe --profile=Work

Use an existing profile for this session only (-p name also works). If it does not exist, nothing is created and the last used profile is used instead. The last selection is not overwritten.

🔗 Profile and Settings Combination

EzCo.exe --profile=Debug --conf:debug.enabled=True

Combine profile specification with setting overrides.

Profile Feature

👤 What is a Profile?

Profiles keep settings, history, and bookmarks separate by purpose (work, personal, and so on). Manage them from the Profile menu (there is no Profile tab in the settings dialog).

📁

Independent Data

Each profile has its own settings, bookmarks, and history that don't affect each other.

⚡

Easy Switching

Choosing a profile from the menu immediately applies spread mode, background, language, shortcuts, and more.

🚀

Startup Specification

Specify a profile for the current session via command-line arguments.

🔧

Management

Add, rename, or delete from the menu. Add copies the current settings (including plugin handlers); bookmarks and history stay empty. The default profile cannot be deleted. A missing CLI name is not created.

Profile Usage Examples

Command Description
EzCo.exe --profile=Work Launch with "Work" profile
EzCo.exe --profile=Personal Launch with "Personal" profile
EzCo.exe --profile="Research Materials" Launch with "Research Materials" profile
※ Uses the last profile if it does not exist

Main Configurable Settings

Setting Example Description
archive.enabled --conf:archive.enabled=False Enable/disable archive file support
window.auto_resize --conf:window.auto_resize=True Auto-resize window when loading images
window.always_on_top --conf:window.always_on_top=True Keep window always on top
viewer.fit_to_window_minimum --conf:viewer.fit_to_window_minimum=False Minimum scale restriction (up to 100%)
viewer.mouse_lock --conf:viewer.mouse_lock=True Mouse lock functionality
debug.enabled --conf:debug.enabled=True Debug mode
language.code --conf:language.code=en Language setting (ja/en/system)

Value Types

Type Acceptable Values Example
Boolean True, False, yes, no, on, off, 1, 0 --conf:debug.enabled=True
Numeric Integer or decimal numbers --conf:cache.prefetch_pages=10
String Any text --conf:language.code=en

⚠️ Important Notes

  • Overridden settings are disabled (grayed out) in settings screens and menus
  • Persistent values in the settings database (config.db) are not modified. Use the settings screen for permanent changes
  • Gesture and shortcut settings cannot be changed via command-line arguments
  • Non-existent setting items are ignored if specified

🚀 Advanced Features

Archive File Support

EzCo supports a wide variety of archive formats, allowing you to directly view images inside compressed files without extracting them first.

📦 Supported Formats

ZIP, 7Z, RAR, CBZ, CBR, TAR, TAR.GZ, TAR.BZ2, TAR.XZ, GZ, BZ2, XZ, PDF

⚙️ File Settings

Choose Built-in, a plugin, or Don't load per extension in Settings → File Settings

Mouse Gestures

Mouse gestures allow you to quickly perform common actions by drawing patterns with the right mouse button.

🖱️ How to Use Gestures

  1. Hold down the right mouse button
  2. Drag the mouse in the desired direction(s)
  3. Release the right mouse button to execute the action
Gesture Action Description
← Previous Comic Move to the previous comic file
→ Next Comic Move to the next comic file
↓ Exit Application Close EzCo
↑ Toggle Fullscreen Switch between fullscreen and windowed mode
↑↓ Reopen Last File Open the last opened file

Bookmarks

Save your favorite pages and organize them in folders for quick access.

📑 Add Bookmark

Press Ctrl + Shift + B or use the menu to bookmark the current page.

📁 Organize Bookmarks

Create folders to organize your bookmarks by series or category.

History

EzCo automatically keeps track of recently viewed files and their last viewed pages.

💡 History Features

  • Automatically saves the last viewed page for each file
  • Configurable history limit (1-99 entries)
  • Quick access through the history sidebar
  • Automatic cleanup of deleted files

Virtual Paths

Virtual paths allow you to directly reference specific files within archive files.

📋 Virtual Path Format

archive://path/to/archive.zip#internal/file.jpg

This format allows you to create shortcuts or links that open specific images within archive files.

⚙️ Settings

EzCo provides extensive customization options through its settings system. Access settings via Settings → Settings in the menu.

Window Settings

Setting Description Default
Auto-resize window Automatically adjust window size when loading images Disabled
Save window state Remember window size and position Disabled
Always on top Keep window in front of other applications Disabled

Viewer Settings

Setting Description Default
Background color Color displayed behind images Light green
Fit to window Automatically scale images to fit the window Disabled

Shortcut Configuration

Customize keyboard and mouse shortcuts for all actions through Settings → Shortcut Settings.

Language Settings

EzCo supports multiple languages and automatic language detection.

🌐 Language Support

  • Built-in Languages: Japanese (ja) and English (en)
  • Custom Languages: Add your own language files in the langs folder
  • System Default: Automatically detects your system language
  • Fallback Behavior: When loading external language files, undefined keys display as the key name itself

Font Settings

Customize the appearance of UI popups and overlays.

🔧 Troubleshooting

Debug Mode

Enable debug mode to generate detailed logs for troubleshooting issues.

1

Enable Debug Mode

Go to Settings → Settings → Debug Settings and check "Debug Mode".

2

Restart Application

Close and restart EzCo to begin logging.

3

Check Logs

Debug logs are saved in the logs folder with timestamps.

Common Issues

🚫 Archive Files Won't Open

Check Settings → File Settings and make sure the extension is not set to Don't load.

🔤 Garbled Text in Archives

EzCo automatically detects encoding, but some files may not display correctly due to encoding issues.

Configuration Files

📁 Important Files and Folders

  • logs/: Debug log files (when debug mode is enabled)
